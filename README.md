# FDE-Deloitte

Projeto iniciado com o framework **BMAD (Breakthrough Method for Agile AI-Driven Development)**.

## Estrutura do Projeto

- **`.agent/skills/`**: Skills configuradas para o Google Antigravity.
- **`.agents/skills/`**: Skills configuradas para Cursor e outros agentes compatíveis.
- **`_bmad/`**: Configurações e módulos do framework BMAD Core e BMM (BMad Method).
- **`_bmad-output/`**: Diretório padrão para geração de artefatos de planejamento e implementação.

## Pré-requisitos

- **Node.js**: v20+
- **Python uv**: Instalado e disponível (`uv` é utilizado para executar os scripts do BMAD)
- **Git**

## Como Usar o BMAD

Para explorar os comandos e fluxos disponíveis, você pode invocar a skill `bmad-help` no seu agente ou executar:

```bash
npx bmad-method status
```
